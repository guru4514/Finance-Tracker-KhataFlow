# Screenshots Guide

Take these screenshots for your README and project report:

## Required Screenshots (add to this folder)

1. **personal-mode.png** — Dashboard in Personal Mode showing stats and customer list
2. **org-mode.png** — Organization Mode with agent view and real-time data
3. **portal.png** — Customer Portal passbook view
4. **daily-entry.png** — Daily Entry grid with amount chips and paid/pending status
5. **dashboard.png** — Dashboard with charts showing collection trends
6. **dark-mode.png** — Any screen in AMOLED dark theme
7. **android-app.png** — App running on Android device or emulator
8. **reports.png** — Reports/Analytics view with Chart.js graphs

## How to Take Good Screenshots

1. Open app at `http://localhost:8080`
2. Add 10-15 demo customers with varied amounts and dates
3. Record some payments so charts have data
4. Use browser DevTools → Toggle Device Toolbar (Ctrl+Shift+M) for mobile views
5. For dark mode: toggle theme in Settings
6. Take screenshot: `Win + Shift + S` (Windows) or DevTools → Capture screenshot

## Recommended Size
- Desktop: 1280x800
- Mobile: 390x844 (iPhone 14 size)
