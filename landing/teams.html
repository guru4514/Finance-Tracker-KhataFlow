5-Level role hierarchy

Each role has carefully calibrated permissions. Agents can only see their own customers.

Owner

Full control. Manages organization settings, members, and all data.

↓

Admin

Approves agent actions. Manages customers and payments.

Manager

Views all data. Can manage assigned agents and customers.

↓

Agent

Collects payments from assigned customers. Needs approval to save.

Viewer

Read-only access. Can view data but cannot make any changes.
